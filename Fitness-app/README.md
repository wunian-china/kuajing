# 一起健身 · 微信小程序

一个「健身打卡 + 好友组队」的微信小程序：支持每日打卡、数据统计、邀请好友组队、多人实时打卡排行。数据基于**微信云开发**（云函数 + 云数据库 + 实时数据推送）。

## 项目结构

```
Fitness-app/
├── app.js / app.json / app.wxss         # 全局入口与配置
├── project.config.json                  # 项目配置（含 cloudfunctionRoot）
├── sitemap.json
├── images/                              # TabBar 图标
├── utils/
│   ├── store.js                         # 纯工具：类型 / 日期 / 统计计算
│   └── api.js                           # 云开发数据访问层（含实时监听）
├── pages/
│   ├── index/                            # 打卡首页
│   ├── checkin/                          # 记录打卡
│   ├── team/                             # 好友组队（实时排行）
│   └── profile/                          # 我的
└── cloudfunctions/
    └── api/                              # 云函数：用户 / 打卡 / 战队
```

## 一、准备工作

### 1. 注册小程序账号并获取 AppID
1. 打开微信公众平台：https://mp.weixin.qq.com
2. 点击「立即注册」→ 选择「小程序」，用邮箱注册（个人主体即可，云开发个人可用）。
3. 完成注册并登录后，进入 **管理后台 → 开发管理 → 开发设置**。
4. 复制页面中的 **AppID**（形如 `wx1234...`）。

### 2. 安装微信开发者工具
1. 下载页：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选择「稳定版 Stable Build」下载并安装。
3. 首次打开用「微信」扫码登录。

---

## 二、导入项目

1. 打开微信开发者工具，首页点「+」或「导入项目」。
2. 目录选择本项目根目录 `Fitness-app`。
3. 填写你刚复制的 **AppID**（不要再用 `touristappid`，游客模式无法使用云开发）。
4. 后端服务选择「微信云开发」（如果此处没有选项，导入后手动开通即可）。
5. 点击「导入」，等待编译完成。

---

## 三、开通云开发

1. 在开发者工具顶部工具栏点击「**云开发**」按钮。
2. 首次会提示「开通」，点击开通并创建一个环境（环境名随意，如 `fitness`）。
3. 开通后进入「云开发控制台」→ 顶部「**设置**」→ 找到「**环境 ID**」（形如 `fitness-xxxx`），复制。

### 配置环境 ID
打开 [utils/api.js](utils/api.js)，把环境 ID 填进去：

```js
const ENV_ID = '';  // 改成你的环境 ID，例如 'fitness-1gxxxxx'
```

---

## 四、创建数据库集合并设置权限

在「云开发控制台」→「**数据库**」中，新建 3 个集合：

| 集合名 | 用途 | 权限设置（数据权限） |
|--------|------|---------------------|
| `users`    | 用户资料 | 仅创建者可读写 |
| `teams`    | 战队信息 | 所有用户可读，仅管理员可写 |
| `checkins` | 打卡记录 | 所有用户可读，仅创建者可写 |

> ⚠️ **关键**：`checkins` 和 `teams` 必须开放「读取」权限（所有用户可读），否则好友之间无法实时看到彼此打卡，团队页实时排行会失效。

设置方法：集合列表 → 点击集合名右侧「权限设置」/「数据权限」→ 按上表选择对应规则 → 保存。

---

## 五、部署云函数

1. 在开发者工具左侧文件树中，找到 `cloudfunctions/api` 目录。
2. 右键 `api` 目录 → 选择「**上传并部署：云端安装依赖**」。
3. 等待提示「部署成功」。

> 若第一次需要选择环境，选择你刚创建的环境即可。

---

## 六、本地预览测试

1. 点击工具栏「编译」，确认首页 / 打卡 / 好友 / 我的四个页面加载正常。
2. 测试打卡：首页「立即打卡」→ 选运动 → 提交 → 返回首页应显示今日分钟数。
3. 测试组队：好友页 →「创建战队」→ 复制邀请码。
4. 用**另一台设备/另一个微信号**打开同一个项目（或真机预览），在好友页「输入码加入」，双方页面应**实时**看到对方打卡状态变化（无需手动刷新）。

> 真机预览：工具栏「预览」→ 生成二维码 → 手机微信扫码。

---

## 七、上传发布到微信小程序

### 1. 上传代码
1. 确认代码无报错后，点击工具栏右上角「**上传**」按钮。
2. 填写「版本号」（如 `1.0.0`）和「项目备注」（如「首个版本」）。
3. 点击「上传」，成功后代码会进入微信公众平台后台。

### 2. 提交审核
1. 登录微信公众平台：https://mp.weixin.qq.com
2. 进入 **管理 → 版本管理**。
3. 在「开发版本」下找到刚上传的版本，点「**提交审核**」。
4. 按提示填写：
   - 功能页面/服务类目（建议选「生活服务 → 运动健身」或相近类目）。
   - 页面截图、审核信息等（首次提审需完善小程序信息）。
5. 提交后等待审核（通常 1~7 个工作日）。

### 3. 发布上线
1. 审核通过后，回到 **版本管理**，该版本会出现在「审核通过」区。
2. 点击「**发布**」→ 扫管理员微信确认 → 完成。
3. 发布后，用户即可在微信小程序中搜索并使用。

## 八、常见问题

- **报「加载失败，请检查云环境配置」**：检查 `utils/api.js` 的 `ENV_ID` 是否填写、云函数是否部署成功、集合是否创建齐全。
- **好友看不到我的打卡**：确认 `checkins`、`teams` 集合权限为「所有用户可读」。
- **无法使用云开发**：请确保项目用的是**真实 AppID**（不能用 `touristappid` 游客模式）。
- **云函数调用报错**：右键云函数重新「上传并部署：云端安装依赖」，或查看「云开发控制台 → 云函数 → 日志」。
- **TabBar 图标不显示**：确认 `images/` 目录下的 6 张 PNG 未被删除。

## 数据说明

- 收藏集：`users`（用户）、`teams`（战队）、`checkins`（打卡记录）。
- 实时同步：团队页通过云数据库 `watch` 监听本队「今日打卡」与「战队成员」变化，实现多人实时刷新。
- 打卡日期以北京时间（UTC+8）为准，云端统一计算。
