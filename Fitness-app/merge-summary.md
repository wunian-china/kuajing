本次合并新增了一个完整的微信小程序「一起健身」健身打卡应用，包含打卡、首页数据概览、团队组队、个人中心四大页面，以及基于本地存储的数据层，实现了运动打卡、数据统计和目标管理等功能。

| 文件 | 变更 |
|------|---------|
| utils/store.js | - 新增数据层模块，封装用户、记录、团队三类数据的本地存储读写及初始化逻辑<br>- 定义跑步、力量、瑜伽等 6 种运动类型常量<br>- 实现连续打卡、累计天数、累计时长等统计计算函数<br>- 实现本周 7 天打卡日期、今日打卡分钟数等辅助函数<br>- 实现邀请码随机生成、刷新与加入团队的模拟逻辑 |
| app.js | - 新增应用入口文件，在启动时调用 store.init() 初始化本地存储数据 |
| app.json | - 注册首页、打卡、团队、我的四个页面<br>- 配置导航栏与「打卡/好友/我的」底部 TabBar<br>- 设置绿色主题配色、sitemap 与懒加载等全局配置 |
| app.wxss | - 新增全局样式，定义配色变量、通用容器、卡片、主/次按钮、文本与布局等工具类 |
| pages/index/index.js | - 新增首页逻辑，加载用户信息、统计数据、今日进度与本周打卡数据<br>- 根据时间生成问候语并计算今日目标进度<br>- 实现跳转打卡页和带运动类型的快捷打卡 |
| pages/index/index.json | - 新增首页配置，设置标题并开启下拉刷新 |
| pages/index/index.wxml | - 新增首页界面，展示问候、今日运动进度与目标进度条<br>- 展示连续打卡、累计天数、累计时长统计<br>- 提供运动类型快捷打卡、本周打卡日历与最近记录列表 |
| pages/index/index.wxss | - 新增首页样式，实现渐变 Hero 区、进度条、统计卡、周历与记录列表等视觉样式 |
| pages/checkin/checkin.js | - 新增打卡页逻辑，加载运动类型并支持选择类型、设置时长与备注<br>- 校验输入后写入打卡记录并返回上一页 |
| pages/checkin/checkin.json | - 新增打卡页配置，设置标题「记录打卡」 |
| pages/checkin/checkin.wxml | - 新增打卡页界面，包含运动类型网格、时长滑块、备注输入与打卡提交按钮 |
| pages/checkin/checkin.wxss | - 新增打卡页样式，实现类型网格选中态、时长数值展示与备注输入框样式 |
| pages/team/team.js | - 新增团队页逻辑，聚合本人与成员打卡数据并统计已打卡人数<br>- 实现复制/刷新邀请码、通过邀请码加入队伍及分享逻辑 |
| pages/team/team.json | - 新增团队页配置，设置标题「好友一起打卡」 |
| pages/team/team.wxml | - 新增团队页界面，展示队伍横幅、邀请码、邀请/加入按钮、成员打卡排行与加入弹窗 |
| pages/team/team.wxss | - 新增团队页样式，实现队伍横幅、邀请码卡片、成员列表与弹窗遮罩等样式 |
| pages/profile/profile.js | - 新增个人中心逻辑，加载用户、统计与全部记录<br>- 实现昵称编辑保存、每日目标设置与清空全部记录功能 |
| pages/profile/profile.json | - 新增个人中心配置，设置标题「我的」 |
| pages/profile/profile.wxml | - 新增个人中心界面，展示个人卡片、统计、每日目标滑块、全部记录与清除按钮 |
| pages/profile/profile.wxss | - 新增个人中心样式，实现个人卡片、统计卡、记录列表与清除按钮样式 |
| project.config.json | - 新增小程序项目配置文件，设置编译类型、基础库版本与编译选项 |
